BLC Stream Hub 개인정보처리방침 · 이용약관

최종 수정: 2026-11-07 · 적용 대상: BLC Stream Hub (방송용 채팅 · 림월드 연동 허브) · English

1. 이 앱은 무엇인가요

BLC Stream Hub(이하 "허브")는 이 모드를 사용하는 모든 방송인이 자기 방송에 쓰는 프로그램입니다. 치지직 · 유튜브 라이브 채팅과 후원을 받아 방송 화면(오버레이)에 보여 주고, 게임 「림월드」와 연동합니다. 허브는 각 방송인의 PC 에서만 동작하며 별도의 외부 서버가 없습니다. 시청자 정보는 그 방송인의 PC 에만 저장되고, 허브 개발자나 다른 방송인에게 전달되지 않습니다.

2. YouTube API 서비스 사용

  • 허브는 YouTube API 서비스를 사용합니다. 허브를 사용하면 YouTube 서비스 약관의 적용을 받는 데 동의하는 것입니다.
  • 유튜브에서 받은 정보는 Google 개인정보처리방침의 적용도 받습니다.

3. 어떤 정보를 받나요

  • 라이브 채팅 · 후원 (시청자): 유튜브 채널 ID, 표시 이름, 채팅 메시지, 슈퍼챗 금액과 메시지 (YouTube Data API 의 라이브 채팅). 치지직도 같은 종류의 정보를 받습니다.
  • 방송인 계정 (방송인 본인만): 방송인이 직접 구글 로그인하면 youtube.readonly(읽기 전용) 권한의 토큰을 받아, 방송인 채널에서 진행 중인 방송을 찾는 데만 씁니다. 허브는 유튜브 비밀번호를 받거나 저장하지 않습니다.
  • 허브는 쿠키 · 광고 추적을 쓰지 않으며, 서드 파티가 광고 등 콘텐츠를 게재하지 않습니다.

4. 어디에 쓰나요

  • 방송 화면에 채팅 · 후원을 보여 주기 (출처가 YouTube 인 내용에는 YouTube 표시를 붙입니다)
  • 채팅 명령으로 게임 「림월드」 안에 효과 · 정착민 등을 일으키기
  • 시청자별 방송 내 포인트(은) · 기록 관리 — 채팅 수 · 분당 채팅 같은 숫자는 YouTube 가 준 값이 아니라 허브가 직접 센 값입니다
  • 유튜브 시청자에게는 채팅 · 시청 같은 참여에 대한 포인트를 주지 않습니다. 유튜브 시청자의 포인트는 슈퍼챗 · 멤버십 후원과 방송인의 수동 지급으로만 생깁니다.

5. 어디에 얼마나 보관하나요

  • 모든 정보는 방송인 PC 의 허브 데이터 폴더에만 저장되며, 판매하거나 다른 사람 · 회사와 공유하지 않습니다. 단, 채팅 · 닉네임은 방송 화면에 공개적으로 표시됩니다.
  • 유튜브 정보 30일 규칙: 30일 동안 새로 받지 않은 유튜브 시청자 정보는 공식 API 로 새로 받고, 채널이 없어졌으면 삭제합니다. 30일 지난 유튜브 후원 메시지 · 이름과 끝난 지 30일 지난 명령 기록은 삭제합니다 (허브가 6시간마다 자동으로 정리).
  • 방송인 로그인 토큰은 방송인이 로그아웃하거나 권한을 취소할 때까지 보관하며, 취소되면 바로 지웁니다.

6. 삭제 요청 · 권한 취소

  • 시청자: 방송 채팅이나 아래 연락처로 방송인에게 요청하면 허브에 저장된 내 정보(포인트 · 기록 포함)를 7일 안에 삭제합니다. 허브에서 지워도 YouTube 에 있는 정보(채팅 등)는 지워지지 않으며, 그것은 YouTube 에서 직접 지워야 합니다.
  • 방송인: 허브 설정 → 유튜브 → '로그아웃 (권한 취소)' 를 누르거나, Google 보안 설정 페이지에서 허브의 접근 권한을 취소할 수 있습니다. 취소되면 허브는 토큰과 그 권한으로 받은 정보를 지웁니다.

7. 이용약관

  • 허브는 이 모드를 사용하는 각 방송인이 자기 방송에서 쓰기 위한 프로그램입니다. 각 방송인은 자기 Google Cloud 프로젝트 · API 키를 직접 만들어 쓰고, 자기 방송에서 받은 시청자 정보를 이 방침에 따라 관리할 책임이 있습니다. 시청자가 채팅 명령을 쓰면 이 방침과 YouTube 서비스 약관에 동의하는 것으로 봅니다.
  • 방송 내 포인트(은)는 현금 가치가 없고 사고팔 수 없습니다.

8. 문의

저장된 내 정보의 삭제 요청은 그 방송의 방송인에게 해 주세요 (정보는 그 방송인의 PC 에만 있습니다). 허브 · 이 방침에 대한 문의: 개발 · 운영 블레시 — wlswlahem@naver.com

Privacy Policy & Terms (English)

Last updated: 2026-11-07 · Applies to: BLC Stream Hub

1. About

BLC Stream Hub ("the Hub") is a desktop tool that every streamer who uses this mod runs for their own live streams. It reads live chat and donations from Chzzk and YouTube, shows them on the stream overlay and connects them to the game RimWorld. The Hub runs only on each streamer's own PC; there is no external server. Viewer data stays on that streamer's PC and is never sent to the Hub's developer or to other streamers.

Each streamer creates and uses their own Google Cloud project and API credentials and is responsible for handling the viewer data from their own stream according to this policy.

2. YouTube API Services

The Hub uses YouTube API Services. By using the Hub you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

3. Information we access

  • Live chat and Super Chats: channel ID, display name, message text and Super Chat amount/message.
  • Streamer account only: an OAuth token with the youtube.readonly scope, used solely to find the streamer's own active broadcast. The Hub never asks for or stores YouTube passwords.
  • No cookies, no ad tracking, no third-party content or ads.

4. How we use it

To display chat and donations on the stream (YouTube content is labelled as coming from YouTube), to trigger in-game events in RimWorld from chat commands, and to keep per-viewer in-stream points. Counts such as chat counts or chats per minute are calculated by the Hub itself and are not YouTube data. YouTube viewers never receive points for engagement such as chatting or watching; their points come only from Super Chats, channel memberships and manual grants by the streamer.

5. Storage and retention

All data is stored locally on the streamer's PC and is never sold or shared (chat and names are shown publicly on stream). Unauthorized YouTube data is refreshed through the API or deleted within 30 days: viewer records are refreshed via channels.list (deleted if the channel no longer exists); YouTube Super Chat messages/names and finished command logs older than 30 days are deleted. OAuth tokens are kept until the streamer logs out or revokes access, then deleted immediately.

6. Deletion and revocation

Viewers can ask the streamer to delete their stored data; it will be deleted within 7 days. Deleting data in the Hub does not delete data stored by YouTube. The streamer can revoke access in the Hub (Log out) or at the Google security settings page.

7. Contact

To delete your stored data, contact the streamer of the stream you watched (the data exists only on their PC). Questions about the Hub or this policy: developer Blreci — wlswlahem@naver.com
